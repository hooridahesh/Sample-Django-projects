# Summary of the content of each project:
#### 🔸days_project:
This is my first project with Django. In this project, a list of days of the week is displayed and by clicking on each day, the page related to that day is displayed and its details are displayed.
Also, if a number between 1 and 7 is entered after the phrase "day/" in the "URL" instead of the day name, it will be automatically redirected to the corresponding day. If a number or word other than days of the week is entered, the message "This page does not exist" will be displayed.  
In this project, the main focus is on learning and not much attention has been paid to the style section.  
To see more details, check the project. The main project file is called "config".
#### 🔸Blog_project:
This is my second project.  
On the main page, only two courses that have been published recently are displayed among all the courses. By clicking on the "All Posts" option, the complete list of courses can be viewed. Also, by clicking on each course, you will enter the details page of that course.  
In this project, more attention has been paid to styles and the appearance of the project is more complete than the previous one.  
For more details, you can view the project. The main project file is called "blog_project".
#### 🔸eshop_project:
This is my third and final project, which is related to a shopping website.  
In this project, a ready-made template was used for the user interface section and then the necessary changes and developments were applied to it to implement the main sections of the store.  
In the main menu, the "Home", "Products" and "Contact Us" pages have been implemented.  
Also, if the user is not logged in, the "Shopping Cart", "User Panel" and "Logout" options will not be displayed to him.  
On the products page, a number of products have been placed. The user can click on "View Details" to enter the page for each product and add it to the shopping cart, increase or decrease its quantity, and then view their shopping cart. They can remove the product from the shopping cart or change its quantity.  
It is also possible to filter products by category, brand, and price filter.  
This project uses models, class-based views, forms, and database connections.  
You can check the project for more details. The main project file is called "eshop".
